# Changelog

## [1.0.0] - 2026-10-27

### Added
- Independent URL architecture for `jichangdiyi.cc`.
- Fully self-hosted local font typography via `@fontsource/inter`.
- Complete JSON-LD Structured Data (WebSite, HealthClub, BlogPosting, BreadcrumbList).
- Strict trailing-slash policy (`never`) and canonical URL generation.
- Modern high-definition Open Graph and Twitter summary cards.
- Web app manifest and hardened Content Security Policy.
